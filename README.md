# BTC 信号助手 V5.6（现货 + U本位永续辅助研判）

Android 原生 Kotlin 应用。使用 Binance、OKX、Bybit 公开行情，不需要 AI API Key，不接入交易账户，不自动下单。

## V5.6 更新

1. **修复合约多空数据解析**：Binance U本位永续的 `globalLongShortAccountRatio` 和 `takerlongshortRatio` 接口返回 JSON 数组，不是 `{data: [...]}` 对象；已按实际响应结构解析。
2. **合约接口独立容错**：资金费率/标记价、未平仓量、多空账户比、主动买卖量比独立获取。单个接口失败不会清空其他可用指标，界面显示可用项数量和更新时间。
3. **保留现货多源行情**：Binance、OKX、Bybit 实时价格交叉验证；至少1路新鲜数据可启动分析，多路数据用于一致性检查。
4. **保留10分钟与30分钟分析**：分别使用1m和5m主周期，结合5m/15m/1h辅助周期；有效行情下始终给出看涨或看跌方向，条件不足只降低规则评分。
5. **保留智能规则知识库**：EMA趋势、RSI动量、成交量、多周期结构，以及江恩、琳达·拉什克、威科夫规则。
6. **保留快照战绩**：记录启动价格、时间、到期快照和结算结果；待结算记录留在“当前开单中”，历史记录可展开/收起；名人堂独立统计。
7. **版本号**：versionCode 11，versionName 5.6。

## 重要说明

- 规则评分是规则匹配程度，不是胜率概率，也不是收益保证。
- 合约数据只作为有限权重的辅助确认，不覆盖现货价格结构。
- 单一行情源、合约数据缺失或行情延迟时，判断可靠性会下降；请结合界面状态人工判断。
- 应用不接入交易账户，不会自动下单。

## 周期设置

| 分析期限 | 主周期 | 辅助周期 |
|---|---|---|
| 10分钟 | 1分钟K线 | 5分钟、15分钟、1小时 |
| 30分钟 | 5分钟K线 | 15分钟、1小时 |

## 编译

- JDK 17
- Gradle 8.9
- Android Gradle Plugin 8.7.3
- Kotlin 2.0.21
- Android SDK 35

在项目根目录运行 `gradle assembleDebug`。GitHub Actions 工作流位于 `.github/workflows/build-apk.yml`。


## V5.6 增强

1. **增加市场状态识别**：按趋势强弱、周期方向与ATR波动识别趋势上涨、趋势下跌、震荡、方向切换和高波动。
2. **增强指标融合**：在原有EMA、RSI、MACD、成交量和策略模块基础上，增加滚动VWAP、MACD柱体方向、OBV量价方向代理及ATR偏离风险。
3. **风险分级**：每次预测记录市场状态、低/中/高风险等级和具体风险提示；方向仍按用户要求给出看涨或看跌，不把方向判断等同于开仓建议。
4. **知识库界面**：增加可展开的技术规则说明，明确RSI、突破、OBV和合约数据的适用边界。
5. **兼容历史记录**：新增记录字段均有默认值，旧版SharedPreferences快照仍可读取，原有战绩不会因升级而清空。
6. **评分说明**：100分仍是规则匹配评分，不是经校准的上涨概率或胜率；OBV为K线量价代理，不冒称逐笔CVD。
